## Remaining risks

1. **Development pattern.** JOSS asks reviewers whether a project shows sustained
   development rather than rapid code generation. The history has a three-month gap, and
   public coverage describes the first prototype as generated by an AI coding agent. The
   paper discloses this in full; the answer to the question is the design, verification and
   documentation work since then.
2. **Research-use evidence.** The evidence is research communication, teaching, and one
   external researcher's account. No publication yet uses 3D ICE. Adding the specific talks,
   courses and usage figures to the paper strengthens it.
3. **Data availability.** The basal-friction input (`taub_med.nc`) and the WAOM2 input
   (`ocean_avg_yr5_annual.nc`) have no documented public download, and the Antarctic
   velocity packages were built from a derived copy of NSIDC-0754. See
   [docs/data-pipeline.md](docs/data-pipeline.md).
4. **Runtime size.** `static/tools/js/explorer-app.js` is still a single orchestration
   module of about 10,000 lines.

      pull request's CI run).
